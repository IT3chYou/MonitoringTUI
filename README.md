
# 🚀 Advanced System Monitor TUI

---

## English

A powerful and aesthetic **Terminal User Interface (TUI)** for real-time system monitoring. Built with Python and the `rich` library, this tool provides a comprehensive overview of your CPU, RAM, Disk, and Network performance with interactive features.

### ✨ Features
*   **Real-time Monitoring:** Live updates for CPU cores, memory usage, and disk I/O.
*   **Advanced Network Insights:** Monitor network traffic, public IP info, and integrated speed tests.
*   **Process Management:** Detailed views of running processes categorized by resource usage.
*   **Interactive Command Mode:** Run system commands directly within the TUI without exiting.
*   **Dynamic Layouts:** Switch between System, Network, and Process views using hotkeys.

### ⌨️ Hotkeys
| Key | Action |
| :--- | :--- |
| `1` | Toggle Advanced Network Monitoring |
| `2` | Toggle Process Information View |
| `i` | Open Command Input Mode |
| `exit` | (Inside input) Close the application |
